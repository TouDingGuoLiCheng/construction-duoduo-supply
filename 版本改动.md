## 0.1.0

### 新增内容
- 采购清单组行时接入施工队单原料虚拟库存（最多 3 跳，**按本单缺料目标过滤**）：库内骨头/骨粉等可顶掉待购骨粉/骨块数量，且不会被无关单原料配方抢走；**本身已是本单缺料的物品不会被虚拟扣掉**，买进库后对应缺料会减少。拆原料按真实库抵扣；真实材料库不变，界面无额外「虚拟」提示
 - Supply list rows use Construction’s single-ingredient virtual vault stock (up to 3 hops, filtered to current shortages): bones/bone meal in the vault reduce bone-meal/bone-block buy needs without unrelated crafts consuming them. Items that are themselves shortages are not virtually spent, so buying them reduces that line. Ingredient rows credit the real vault; the real vault is unchanged and the UI stays silent about virtual stock
- 采购原料已够库内合成时，该缺料行从清单消失（不再误显示成「无货」且数量不变）
 - When vault stock already covers crafting an out-of-stock finished item, that shortage row is omitted instead of wrongly showing as out-of-stock with the old need count
- 施工终端材料页可打开「多多采购」：按当前工程缺料勾选，确认后按勾选缺量一次买齐（余额不够则买到买不起；特价受卖菜每日上限），从多多卖菜系统商城扣余额采购；支持全选可购、无货标记；货物优先进材料库（含手持终端的世界材料库）
 - Construction Hub materials page can open DuoDuo Buy: select current-project shortages and purchase the full selected quantities in one confirm (partial if the wallet runs out; sale items follow the daily sale cap) from the Homestead Sell Veggies system mall; supports select-all-buyable and out-of-stock marks; items prefer the material vault (including the handheld terminal’s world-backed vault)
- 采购清单行改为「缺 N」与「单价 / 小计」分栏显示，避免被看成库存数量比
 - Supply list rows now show “need N” and “unit / subtotal” labels so prices are not mistaken for stock ratios
- 商城对成品无货时，若工作台/切石机/熔炉高炉/锯子类配方在 5 层内可整组拆到可购原料，则在目标名旁列出原料行（数量与单价按原料），便于配合施工队缺料自动合成
 - When a finished shortage is out of stock in the mall, if crafting-table/stonecutter/furnace/blast-furnace/woodcutting recipes can fully expand to buyable leaves within depth 5, the list shows ingredient rows beside the target (qty/price for ingredients) so vault auto-craft can finish the job
