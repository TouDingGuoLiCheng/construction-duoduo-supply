# 采购虚拟库存按需增强 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 材料库有骨粉时，采购清单待购骨粉应减少；禁止虚拟单原料把骨粉贪心搓成白染料等与当前缺料无关的产物。

**Architecture:** `VaultVirtualSingleCraftStock` 增加「朝目标产物闭包」过滤：只对能通向当前缺料 purchaseItemId 的单原料配方做虚拟搓合。多多 `buildRows` 传入本单材料目标集合。拆原料仍用增强后的计数（目标向增强后骨粉会进骨块，差额正确）。

**Tech Stack:** Java 17、JUnit5（施工队 unitTest）、Forge 1.20.1 API。
