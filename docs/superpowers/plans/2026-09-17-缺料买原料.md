# 缺料买原料 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 商城无货的施工缺料，在 5 层配方内可整组拆到可购原料时，清单改为买原料行。

**Architecture:** 施工队新增只读 `VaultPurchaseIngredientPlanner` + `ConstructionSupplyApi.listPurchaseIngredients`；多多采购在 `SupplyListService.buildRows` 对不可购行调用拆解并展开 UI 行。

**Tech Stack:** Java 17, Forge 1.20.1, JUnit 5 unitTest

## Global Constraints

- 采购侧深度上限固定 **5**（与自动合成 DEFAULT_MAX_DEPTH=8 独立）
- 全有或全无；库内原料扣减；同原料按成品分行；不碰自动合成开关
- 实验分支：施工队 `exp/construction`；多多采购 `exp/construction_duoduo_supply`；不改 `mod_version`
